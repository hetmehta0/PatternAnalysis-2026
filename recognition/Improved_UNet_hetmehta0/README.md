# Improved U-Net for Prostate MRI Segmentation

COMP3710 Pattern Recognition — Semester 2, 2026

## Project objective

Investigate whether a 2D Improved U-Net provides better prostate
segmentation accuracy and boundary quality than a standard 2D U-Net
on the HipMRI dataset.

## Dataset

HipMRI Study — 2D MRI slices.

## Models

- Baseline: Standard 2D U-Net
- Proposed: 2D Improved U-Net

## Evaluation

- Prostate Dice coefficient
- Intersection-over-Union (IoU)
- Boundary failure analysis
- Computational resource comparison
